# WebGL Learning

面向 7 年前端架构师的 WebGL 系统课程仓库。

本仓库按课程逐步增加：每课包含中文文档、带注释源码、独立可运行 demo，并在每课完成后提交和推送。

## 快速开始

```bash
npm run lint
npm run test
npm run typecheck
```

运行某一课：

```bash
cd lessons/01-canvas-context
python3 -m http.server 5173
# 打开 http://localhost:5173/index.html
```
